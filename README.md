# Global Airline Passenger Analytics

## Project Overview
Analyzed global airline passenger data using **SQL, Excel, and Tableau** to identify passenger trends, airport performance, route patterns, and key business KPIs. Developed an interactive Tableau dashboard to deliver actionable insights for data-driven decision-making.

## Business Objective
- Analyze passenger traffic trends
- Identify high-performing airports and routes
- Understand passenger flow patterns
- Identify peak travel periods
- Track key airline and airport performance KPIs

## Tools & Technologies
- **SQL** – Data querying and analysis
- **Excel** – Data cleaning and exploratory analysis
- **Tableau** – Interactive dashboards and data visualization

## Key KPIs
- Total Passengers
- Passenger Growth
- Airport Passenger Volume
- Top Routes
- Average Passenger Volume
- Passenger Trends
